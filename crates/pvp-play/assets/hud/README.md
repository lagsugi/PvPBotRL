# Duel HUD sprites

These original pixel drawings were created on blank grids for `pvp-play`.
The 15×15 sight has four corner brackets and a single aiming pixel. The 16×4
charge meter has separate rails and fill so the inversion shader draws each
pixel once. The 16×16 ready mark sits below the sight. The 8×8 copper and
gold spark is drawn as a billboard at the site of a critical hit.
