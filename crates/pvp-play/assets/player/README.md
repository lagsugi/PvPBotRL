# Duelist and armor textures

These three original pixel atlases were drawn on blank grids for `pvp-play`
using the box UV layout in `src/model.rs`.

- `duelist.png` (64×64) depicts a navy training automaton with amber eyes and a copper scarf.
- `duelist_plate.png` (64×32) adds an open turquoise helmet, chest plate, arm guards and boots.
- `duelist_greaves.png` (64×32) adds the belt and articulated thigh plates.

Transparent pixels let the layer beneath show through. The executable embeds all three atlases.
