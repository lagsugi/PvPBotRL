## Data references

D1 refers to the following resources in the official inner server JAR. The investigation checked the actual data in addition to registration code.

- `build/phase1/resources/data/minecraft/enchantment/protection.json` gives 1 per level, covers all ARMOR slots, has maximum level 4, and excludes bypasses_invulnerability.
- `build/phase1/resources/data/minecraft/damage_type/player_attack.json` defines the damage type. Difficulty-based mob damage adjustments do not apply to PvP.
- `build/phase1/resources/data/minecraft/damage_type/fall.json` and `build/phase1/resources/data/minecraft/tags/damage_type/bypasses_armor.json` establish that fall damage bypasses armor.
- Other damage_type tags are extracted to `build/phase1/resources/data/minecraft/tags/damage_type/`. player_attack is absent from bypasses_cooldown and no_knockback, while fall belongs to no_knockback.

Additional tick-end references: `build/phase1/sources-common/net/minecraft/network/protocol/game/ServerboundClientTickEndPacket.java`, Minecraft.java lines 1971–1974 in C7a, and ServerGamePacketListenerImpl.java lines 2139–2145 in N1.

## Reproduction

Run in PowerShell from the repository root using Java 25 as in the existing project.

```powershell
# Only if source JARs are missing. Uses the existing Fabric Loom setup.
.\fabric\gradlew.bat -p fabric genSources

# Verify local JARs and extract generated sources and official bundled libraries under build.
.\tools\research\minecraft\Prepare-Sources.bat

# Run limited probes using official classes without starting the server main.
.\tools\research\minecraft\Run-Probes.bat
```

For a nonstandard Loom cache location, use `Prepare-Sources.bat -LoomCache <path>`. Specify Java with `Run-Probes.bat -Java <java.exe>`.

Generated artifacts:

```text
build/phase1/sources-common/      Generated common sources
build/phase1/sources-client/      Generated client sources
build/phase1/resources/           Target data
build/phase1/runtime/             Server and libraries from the official bundle
build/phase1/provenance.json      Hash verification results
build/phase1/probe-results.json   Numerical probe results
```

`build/` is already ignored by .gitignore. Leave extracted Minecraft source and complete JARs there. The documentation's evidence directory retains the JSON recorded at analysis time. Recheck line references if source JAR hashes change. Prepare-Sources pins distribution hashes for client/server and checks inner JARs and libraries against the bundle's SHA-256 list to avoid testing the wrong version.

The verification section of [implementation-contract.md](implementation-contract.md) describes coverage and outstanding checks. A passing probe establishes agreement only for the tested cases.
